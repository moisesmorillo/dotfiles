# OpenAI 6.2 model update

## Approved scope

Update Pi and OpenCode to use GPT-6.2 Sol wherever their active configuration names an older Sol model.
Add GPT-6.2 Sol and Astra to Pi fast-mode support for both OpenAI providers.
Remove the five superseded Sol and Astra fast-mode entries. Keep GPT-5.6 Sol, Luna defaults, and reasoning levels unchanged.
Update current documentation and command instructions. Keep historical plans unchanged.

## Approaches

- Update both tools. This keeps their Sol routes consistent. The owner selected this approach.
- Update Pi only. This leaves OpenCode on older Sol versions. The owner did not select this approach.

## Constraints and evidence

OpenAI lists `gpt-6.2-sol` and `gpt-6.2-astra` in its release announcement:
https://openai.com/index/introducing-gpt-6-2-astra-sol/

The release supports both models in the API and Codex. No live authenticated inference test is in scope.
No dependency changes, provider changes, or Luna replacements are in scope.

## Verification

Test the managed Pi settings, both provider entries, the eight selected fast-mode entries, and OpenCode routes.
Run all repository shell tests and ShellCheck on changed shell tests.
